# Projeto 1 - Minha identidade na Web

Página pessoal em HTML5 semântico com duas páginas ligadas por caminhos relativos.

## Como abrir
Abra o arquivo `index.html` no navegador. A página complementar fica em `paginas/interesses.html`.

## Estrutura
```
projeto1_pagina_pessoal/
├── index.html
├── README.md
├── paginas/
│   └── interesses.html
├── imagens/
│   ├── avatar.svg
│   └── violao.svg
└── midias/
    └── acorde-mi-maior.wav
```

## Recursos usados
- header, nav, main, section e footer nas duas páginas
- Links internos (#id), links externos e links de ida e volta entre as páginas
- Imagens locais com texto alternativo
- Lista não ordenada (interesses) e ordenada (objetivos)
- Tabela de estudos (tema, conhecimento atual, próximo passo)
- Elemento audio com controls e source (sem autoplay)
- Formulário demonstrativo com label for/id, name, type="email" e required

## Registro de testes
- Links internos, externos e de ida/volta testados no navegador.
- Áudio reproduzido com os controles.
- Formulário não envia dados (botão type="button").

## Origem dos materiais
Imagens (SVG) e áudio criados pelo autor.
