# Projeto 4 - Interface Responsiva com Bootstrap

**Integrante:** Gustavo Luiz Borges - RGM 42944490 (individual).

Vitrine de cursos fictícia (Trilha Dev) feita com Bootstrap 5.3 via CDN.

## Como abrir
Abra `index.html` no navegador (é preciso internet para carregar o Bootstrap pelo CDN).

## Requisitos atendidos
- Cabeçalho com título e breve apresentação.
- Seis cards com título, descrição, categoria (`badge`) e link estilizado como botão (`btn btn-primary`).
- Rodapé com nome completo e RGM.
- Grid responsivo: `container` > `row` > `col-12 col-md-6 col-lg-4` (1 card por linha no celular, 2 em telas médias e 3 em telas grandes).
- Classes de espaçamento (`py-5`, `mb-4`, `g-4`, `p-4`), cores (`bg-primary`, `bg-light`, `text-secondary`), alinhamento (`text-center`, `d-flex`, `mt-auto`, `align-self-start`), aparência (`shadow-sm`, `border-0`, `rounded-3`) e botões (`btn`, `btn-primary`).
- Seção "O que aprendemos" explicando as classes novas `sticky-top` e `stretched-link`.
