Minha primeira página Web

Esta é a minha primeira página criada na disciplina de Desenvolvimento Front-End para Web. Aqui eu pratico a estrutura básica de um documento HTML5.

O que aprendi na primeira aula

  • O que é Front-End e Back-End
  • A estrutura de um documento HTML5
  • Como abrir um arquivo HTML no navegador

Passos para criar uma página

  1. Criar uma pasta para o projeto
  2. Criar o arquivo index.html no editor
  3. Escrever a estrutura básica do HTML5
  4. Salvar o arquivo
  5. Abrir o arquivo no navegador
